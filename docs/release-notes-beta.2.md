# 0.1.0-beta.2 — 首个公开测试版

Windows x64 便携版，解压后运行 CodexGuardian.App.exe，无需安装 .NET SDK。

- 桌面小球查看额度及重置时间；展开后显示今日动态建议。
- 按开发日强度安排当前周余额，设置重要日最低额与总预留。
- 保存并恢复本地计划，账号和重置窗口隔离。
- 余额低于预留时及时提示，历史不足不伪造预测。
- 支持旧安装目录与当前 Windows 商店版 Codex 实时额度读取。
- 修复损坏计划、保存错误提示及跨日重新载入问题。

预算是按剩余额度重新计算的建议，不是官方限额或每日累计消耗。身份缺失时限制保存；仅个人账号用户可在设置中自行确认启用对应选项。重置事件、宠物、安装器和自动更新留待后续。

验证：147 项核心测试通过；Windows 11 x64 实时读取、独立包离线冒烟、演示预算保存和跨进程恢复通过。未验收所有 Windows 版本、团队切换、多屏 DPI 及全部窗口交互。本版本未签名，仍为测试版。
